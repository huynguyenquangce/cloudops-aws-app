Giữ lại trạng thái RAM khi "stop" → boot nhanh hơn vì OS không bị tắt mà chỉ bị "đóng băng".Preserves the in-memory (RAM) state on "stop" → faster boot, because the OS is frozen rather than shut down.

Dữ liệuDataKhi start lạiOn next start
